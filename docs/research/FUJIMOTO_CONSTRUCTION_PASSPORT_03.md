### 1. Идентификатор и название конструкции

* **Идентификатор конструкции:** `FUJ-TWIST3-C01` (альтернативный проектный код: `FUJIMOTO_ROOT_DIVISION_METHOD`).
* **Каноническое авторское название:** Метод деления через квадратные корни (ルート分割法 / `紙面を5等分する ルート分割法` / `2n+1等分法`).
* **Классификация в системе геометрических операций:**
  * **Шаг 1 (Бинарная разметка):** Построение базовых опорных точек $E$ ($x = n$ долей) и $F$ ($x = n+1$ долей) последовательным делением пополам — **Аксиома Худзиты 2**.
  * **Шаг 2 (Поворот хорды на направляющую):** Сгиб через шарнир в вершине $B(0,0)$, переводящий точку $F$ на вертикальную прямую $x = x_E$ — **Аксиома Худзиты 5** (Huzita Axiom 5). Угол оси сгиба $\theta$ удовлетворяет строгому условию $\cos(2\theta) = \frac{x_E}{d_F} = \frac{n}{n+1}$. Ось сгиба продолжается до пересечения с противоположным вертикальным обрезом листа в точке $P$.
  * **Шаг 3 (Построение равнобедренного клина):** Сгибание вершины $B$ на точку $P$ — **Аксиома Худзиты 2 / Примитив B** (построение серединного перпендикуляра к отрезку $BP$).
  * **Результат:** Точка пересечения серединного перпендикуляра с нижней базовой стороной $BC$ делит ее в точном отношении:
    $$\frac{B Q_0}{Q_0 C} = \frac{n + 1}{n}, \quad Q_0 C = \frac{n}{2n+1} BC, \quad B Q_0 = \frac{n+1}{2n+1} BC$$
    Для $n = 2$ сторона делится ровно на 5 частей ($3 : 2$).

### 4. Описание рисунков и обозначенных на них объектов

1. **Стр. 7, Кадр 1:**  
   * Прямоугольник $ABCD$ ($B$ — нижний левый угол, $C$ — нижний правый, $A$ — верхний левый, $D$ — верхний правый).
   * Верхний край $AD$ и нижний край $BC$ имеют середины $M$ и $E$. Прямая $ME$ — вертикальная средняя линия.
   * Правее точки $E$ на отрезке $EC$ нанесена засечка $F$ (середина отрезка $EC$, полученная делением правой половины пополам).
   * Фигурные скобки снизу: отрезок $BE$ обозначен цифрой `2`, отрезок $BF$ обозначен цифрой `3` (цена деления — четверть листа: $BE = 2/4$, $BF = 3/4$).
2. **Стр. 7, Кадр 2:**  
   * Лист складывается по наклонной оси, выходящей из вершины $B(0,0)$.
   * Стрелка показывает дуговое перемещение точки $F$ до совмещения с вертикальной линией $ME$.
   * Правый край листа при этом переламывается, и ось сгиба пересекает правый вертикальный край $CD$ в точке $P$.
3. **Стр. 7, Кадр 3:**  
   * Показана операция складывания вершины $B$ на только что найденную точку $P$.
   * Линия сгиба (серединный перпендикуляр к $BP$) пересекает нижний срез $BC$ в точке $Q_0$.
   * Внизу явно указана пропорция: $B Q_0 : Q_0 C = 3 : 2$.
4. **Стр. 52, Чертеж доказательства:**  
   * Базовый прямоугольный треугольник вверху листа: гипотенуза $n+1$, прилежащий катет $n$, противолежащий катет $\sqrt{(n+1)^2 - n^2} = \sqrt{2n+1}$.
   * Нижний чертеж: показана база $BC$, вертикаль на расстоянии $n$, дуга поворота радиуса $n+1$, луч сгиба до точки $P$ на высоте $CP = \sqrt{2n+1}$, и серединный перпендикуляр, образующий равнобедренный треугольник $\triangle PBQ$ с вершиной $Q$ на базе $BC$.

### 5. Начальная геометрическая конфигурация

* Прямоугольный лист бумаги в декартовых координатах:
  * Вершина $B = (0, 0)$ (начало координат).
  * Вершина $C = (L, 0)$ (длина основания $L > 0$).
  * Вершина $D = (L, H)$, вершина $A = (0, H)$ ($H > 0$ — высота листа).
* Для деления на 5 частей ($n=2$):
  * Вертикальная опорная линия $ME$: $x = x_E = \frac{2}{4} L = \frac{1}{2} L$.
  * Опорная точка на нижнем крае: $F = (x_F, 0) = \left(\frac{3}{4} L, 0\right)$.
  * Отношение координат: $\frac{x_E}{x_F} = \frac{2/4}{3/4} = \frac{2}{3} = \frac{n}{n+1}$.

### 6. Явные геометрические ограничения

1. **Неподвижный шарнир:** Ось сгиба на шаге 2 проходит строго через вершину $B(0,0)$ [*Подтверждено источником*].
2. **Линейное совмещение:** Образ точки $F$ при отражении обязан принадлежать вертикальной прямой $x = x_E$ [*Подтверждено источником*].
3. **Отражение точка-в-точку:** Ось сгиба на шаге 3 является серединным перпендикуляром отрезка $BP$ [*Подтверждено источником*].
4. **Габаритное ограничение:** Точка $P$ должна лежать на вертикальном правом обрезе листа $x = L$, то есть $0 \le y_P \le H$ [*Геометрическое ограничение*].

### 7. Дополнительные предположения

1. **Достаточная высота листа:** Чтобы точка $P$ попала на правый обрез $CD$ (а не на верхний срез $AD$), высота листа должна удовлетворять неравенству:
   $$H \ge y_P = L \cdot \tan\theta$$
   Для $n=2$: $\tan\theta = \frac{1}{\sqrt{5}} \approx 0.4472$. Следовательно, требуется $H \ge 0.4472 L$, то есть отношение сторон листа $L / H \le \sqrt{5} \approx 2.236$.
   Для листа B5 или A4 ($1 : \sqrt{2} \approx 1.414$) это условие выполняется с запасом: $1.414 < 2.236$ [*Математически выведено*].

### 9. Математическое обоснование и строгое доказательство

#### А. Вывод угла оси сгиба на Шаге 2
Пусть ось сгиба проходит через начало координат $B(0,0)$ под углом $\theta$ к горизонтальной оси $Ox$.  
Матрица отражения $R_\theta$ переводит вектор $(x, y)$ с сохранением полярного радиуса, поворачивая его на угол $2\theta$.  
Точка $F$ лежит на оси $Ox$ на расстоянии $d_F = x_F$ от начала координат: $F = (d_F, 0)$.  
Ее образ после отражения относительно оси сгиба:
$$F' = R_\theta(F) = (d_F \cos(2\theta), d_F \sin(2\theta))$$

По условию Фудзимото, точка $F'$ ложится на вертикальную прямую $x = x_E$:
$$d_F \cos(2\theta) = x_E \implies \mathbf{\cos(2\theta) = \frac{x_E}{d_F}}$$

Подставляя значения бинарной разметки $x_E = n$ долей, $d_F = n + 1$ долей:
$$\mathbf{\cos(2\theta) = \frac{n}{n + 1}}$$

#### Б. Определение координат точки $P$ на правом обрезе
Ось сгиба является прямой $y = (\tan\theta) x$.  
Она пересекает правый край листа $x = L$ в точке:
$$P = (L, L \tan\theta)$$

Выразим $\tan\theta$ через $\cos(2\theta) = \frac{n}{n+1}$:
По тригонометрическому тождеству:
$$\tan^2\theta = \frac{1 - \cos(2\theta)}{1 + \cos(2\theta)} = \frac{1 - \frac{n}{n+1}}{1 + \frac{n}{n+1}} = \frac{\frac{1}{n+1}}{\frac{2n+1}{n+1}} = \frac{1}{2n+1}$$
$$\mathbf{\tan\theta = \frac{1}{\sqrt{2n+1}}}$$

Отсюда высота точки $P$:
$$y_P = \frac{L}{\sqrt{2n+1}}$$

#### В. Построение серединного перпендикуляра к отрезку $BP$
Координаты концов отрезка: $B = (0, 0)$, $P = \left(L, \frac{L}{\sqrt{2n+1}}\right)$.
1. Середина отрезка $M_{BP}$:
   $$M_{BP} = \frac{B + P}{2} = \left(\frac{L}{2}, \frac{L}{2\sqrt{2n+1}}\right)$$
2. Вектор $\vec{BP} = \left(L, \frac{L}{\sqrt{2n+1}}\right)$. Его наклон: $k_{BP} = \frac{1}{\sqrt{2n+1}}$.
3. Наклон серединного перпендикуляра:
   $$k_\perp = -\frac{1}{k_{BP}} = -\sqrt{2n+1}$$
4. Уравнение серединного перпендикуляра:
   $$y - \frac{L}{2\sqrt{2n+1}} = -\sqrt{2n+1} \left(x - \frac{L}{2}\right)$$

#### Г. Пересечение с базовым ребром $BC$ ($y = 0$)
Полагаем $y = 0$:
$$-\frac{L}{2\sqrt{2n+1}} = -\sqrt{2n+1} \left(x_{Q_0} - \frac{L}{2}\right)$$
Разделим обе части на $-\sqrt{2n+1}$:
$$\frac{L}{2(2n+1)} = x_{Q_0} - \frac{L}{2}$$
$$x_{Q_0} = \frac{L}{2} + \frac{L}{2(2n+1)} = \frac{L}{2} \left(1 + \frac{1}{2n+1}\right) = \frac{L}{2} \cdot \frac{2n+2}{2n+1} = \frac{n+1}{2n+1} L$$

Следовательно:
$$\mathbf{x_{Q_0} = \frac{n+1}{2n+1} L}$$

Длина левого сегмента:
$$B Q_0 = x_{Q_0} = \frac{n+1}{2n+1} L$$
Длина правого сегмента:
$$Q_0 C = L - x_{Q_0} = L \left(1 - \frac{n+1}{2n+1}\right) = \frac{n}{2n+1} L$$

Отношение сегментов:
$$\mathbf{\frac{B Q_0}{Q_0 C} = \frac{\frac{n+1}{2n+1}}{\frac{n}{2n+1}} = \frac{n+1}{n}}$$

Для деления на 5 частей ($n = 2$):
$$x_{Q_0} = \frac{2+1}{2(2)+1} L = \frac{3}{5} L = 0.6 L$$
$$Q_0 C = \frac{2}{5} L = 0.4 L$$
$$\mathbf{B Q_0 : Q_0 C = 3 : 2}$$
Теорема Фудзимото доказана аналитически с абсолютной строгостью [*Математически выведено*].

### 10. Возможные альтернативные трактовки

1. **Вторая алгебраическая ветвь Аксиомы 5:**  
   Уравнение $\cos(2\theta) = \frac{n}{n+1}$ имеет два решения в интервале $(-\pi, \pi)$: $\theta > 0$ и $\theta < 0$. Отрицательный угол направлен ниже базового среза $BC$ и физически не попадает на лист бумаги.
2. **Отношение $n : (n+1)$ против $(n+1) : n$:**  
   В зависимости от того, от какой вершины измеряются отрезки $n$ и $n+1$, точка $Q_0$ может быть получена на расстоянии либо $\frac{n+1}{2n+1}$, либо $\frac{n}{2n+1}$. В авторском тексте на стр. 7 и 52 Фудзимото всегда ставит больший отрезок $n+1$ слева ($BQ_0$).

### 12. Критерии независимой проверки результата

1. **Координатный критерий:**  
   $$\left| \frac{B Q_0}{BC} - \frac{n+1}{2n+1} \right| < 10^{-12}$$
2. **Инвариант серединного перпендикуляра:**  
   $$\text{dist}(B, \text{Line}(BP)_\perp) = \text{dist}(P, \text{Line}(BP)_\perp) = 0$$
3. **Инвариант совпадения с линией ME:**  
   $$\text{dist}(F', ME) < 10^{-12}$$
