## [1.2.0] — 2026-10-24

### Фаза Gate 1.2: Closure Audit & Evidence Freeze
- Закрыта фаза Gate 1 с официальным вердиктом **`GATE 1 CLOSED WITH DOCUMENTED LIMITATIONS`**.
- Проведена независимая проверка воспроизводимости: подтверждены `npm test` (18/18 PASS), `npm run lint` (0 ошибок), `npm run build` (OK).
- Проверена изоляция отрицательных тестов: подтверждено, что тесты засчитываются как `PASS` только при получении ожидаемого типизированного отказа. Неожиданные сбои инфраструктуры приводят к `FAIL`.
- Исключены некорректные формулировки о «100% точности»: зафиксированы реальные численные невязки $|\Delta| \le 4.44 \times 10^{-16}$ на фикстурах диапазона $L \in [0, 2]$.
- Сформирован **Реестр доказательств (Evidence Registry)** из 19 утверждений с классификацией статусов (`CONFIRMED_BY_TEST`, `CONFIRMED_BY_ANALYTIC_CHECK`, `UNRESOLVED`, `OUT_OF_SCOPE`).
- Зафиксирована заморозка доказательств первого ядра (Evidence Freeze). Разделены направления Gate 2: невыпуклая геометрия и граф наслоения слоёв вынесены в отдельные независимые задачи.
- Оформлен итоговый документ **`EXPERIMENTS/GATE-1.2-CLOSURE-REPORT.md`**.

## [1.1.0] — 2026-10-24

### Фаза Gate 1.1: Independent Implementation Audit & Hardening
- Проведён независимый аудит реализации математического ядра, Zero-Trust валидатора и тестового раннера.
- **Устранён дефект разделения кода (Code Sharing):** Валидатор `src/verifier/independentVerifier.ts` переведён на полностью автономный расчёт метрики расстояний и ориентированной формулы Гаусса.
- **Внедрена защита от нечисловых координат:** Функции `assertValidPoint2D` и `assertValidNumber` в `src/core/reflection.ts` выбрасывают `INVALID_COORDINATE` при обнаружении `NaN` или `Infinity`.
- **Внедрена защита от вырожденного вектора направления:** Функция `assertValidDirection2D` выбрасывает `ZERO_DIRECTION_VECTOR` при попытке сгиба относительно вектора нулевой длины `[0, 0]`.
- **Изоляция исключений в раннере:** Каждый тест в `src/core/testRunner.ts` изолирован в блок `try...catch` для защиты от аварийного завершения.
- **Расширенный аудит наклонных осей:** Добавлен проверочный набор `PCRS-AUDIT-EXT` для произвольного угла $\theta = 30^\circ$ с иррациональными координатами и тестами на выброс исключений.
- Оформлен итоговый аудиторский отчёт **`EXPERIMENTS/GATE-1.1-INDEPENDENT-AUDIT.md`** с вердиктом `PASS WITH BOUNDED GAPS`.

## [1.0.0] — 2026-10-24

### Фаза Gate 1: Minimal Core Implementation & Runtime Verification
- Реализовано каноническое геометрическое ядро плоского отражения (`src/core/reflection.ts`): формулы $R = 2uu^T - I$, аффинные матрицы, формулы Гаусса (Shoelace) для ориентированной и геометрической площади, композиции аффинных преобразований.
- Реализован автономный Zero-Trust валидатор (`src/verifier/independentVerifier.ts`): независимая перепроверка изометрии, неподвижности оси, знаковой Гауссовой инверсии, алгоритм полигонального клиппинга Сазерленда–Ходжмана, классификация 4 типов контактов (`NO_CONTACT`, `VERTEX_CONTACT`, `SEGMENT_CONTACT`, `AREA_OVERLAP`), детектор искусственных сбоев.
- Реализован детерминированный тестовый раннер (`src/core/testRunner.ts`, `scripts/runTests.ts`):
  - Пакет **PCRS-CORE-EXP-001** (8 тестов): 8/8 PASS.
  - Пакет **PCRS-CORE-EXP-002** (7 тестов): 7/7 PASS (включая некоммутативность, параллельный сдвиг, замкнутый цикл $T=I$, негативный контроль).
  - Итого: **15 из 15 тестов успешно выполнены** в среде Float64 с максимальной невязкой $\approx 4.44 \times 10^{-16}$.
- Сформирован официальный отчёт `EXPERIMENTS/GATE-1-VERIFICATION-REPORT.md`.
- Создан интерактивный UI-компонент `ExecutionHarness.tsx` для запуска тестов ядра в браузере в один клик.
