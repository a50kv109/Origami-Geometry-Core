## 1. Контекст и архитектурное разделение серий

В ходе аудита выявлено, что термин «одиночный сгиб и детекция перекрытия» объединяет две различные исследовательские постановки:
1. **Серия EXP-001-A (Single Sheet Internal Crease):** Сгибание исходного цельного листа единичного квадрата вдоль внутренней линии сгиба.
2. **Серия EXP-001-B (Adjacent Faces & Boundary Reflection):** Исследование взаимодействия двух смежных граней развёртки до сгиба (касание по общей границе) и после отражения одной из граней относительно этой границы.

Обе серии стандартизированы ниже как обязательные части тестового пакета PCRS-EXP-001.

## 2. Серия EXP-001-A: Сгиб единичного листа (Unit Square)

### Случай A-1.1: Срединный вертикальный сгиб
- **Лист:** $\mathcal{S}_0 = [0, 1] \times [0, 1]$.
- **Линия сгиба:** $x = 0.5$ (нормаль $n = (1, 0)$, опорная точка $p_0 = (0.5, 0.5)$).
- **Разбиение листа:**
  - Статическая часть: $\mathcal{F}_{\text{static}} = [0, 0.5] \times [0, 1]$, площадь $S_1 = 0.5$.
  - Подвижная часть: $\mathcal{F}_{\text{moving}} = [0.5, 1.0] \times [0, 1]$, площадь $S_2 = 0.5$.
- **Преобразование отражения $R_L$:**
  $$R_L(x, y) = (1 - x, y)$$
- **Образ:** $R_L(\mathcal{F}_{\text{moving}}) = [0, 0.5] \times [0, 1] = \mathcal{F}_{\text{static}}$.
- **Аналитический результат:**
  - Множество пересечения: $\mathcal{I} = [0, 0.5] \times [0, 1]$.
  - Точная площадь: $\operatorname{Area}(\mathcal{I}) = 0.5000000$.
  - Классификация контакта: `AREA_OVERLAP`.
- **Статус:** `DERIVED`.

### Случай A-1.2: Диагональный сгиб
- **Линия сгиба:** $y = x$ ($p_0 = (0, 0)$, нормаль $n = (-\frac{\sqrt{2}}{2}, \frac{\sqrt{2}}{2})$).
- **Разбиение листа:**
  - $\mathcal{F}_{\text{static}} = \triangle [(0,0), (1,0), (1,1)]$, площадь $0.5$.
  - $\mathcal{F}_{\text{moving}} = \triangle [(0,0), (1,1), (0,1)]$, площадь $0.5$.
- **Образ:** $R_L(\mathcal{F}_{\text{moving}}) = \mathcal{F}_{\text{static}}$.
- **Аналитический результат:** $\operatorname{Area}(\mathcal{I}) = 0.5000000$, класс `AREA_OVERLAP`.
- **Статус:** `DERIVED`.

## 3. Серия EXP-001-B: Смежные грани и граничный контакт (Adjacent Faces)

### Случай B-1.1: Контакт смежных граней до сгиба (Pre-Fold Adjacent Contact)
- **Конфигурация:** Две прямоугольные грани на плоскости развёртки:
  - Грань $F_1 = [0, 1] \times [0, 2]$ (ширина 1, высота 2, площадь $S = 2.0$).
  - Грань $F_2 = [1, 2] \times [0, 2]$ (ширина 1, высота 2, площадь $S = 2.0$).
- **Геометрическое пересечение до сгиба:**
  $$F_1 \cap F_2 = \{ (1, y) \mid y \in [0, 2] \}$$
  Пересечение представляет собой отрезок границы длины 2.
- **Аналитический результат:**
  - Топологическая размерность: $\dim(F_1 \cap F_2) = 1$.
  - Мера Жордана (площадь): $\operatorname{Area}(F_1 \cap F_2) = 0.0000000$.
  - Классификация контакта: строго **`SEGMENT_CONTACT`** (касание по границе).
  - **Критическое правило:** Данное состояние **категорически не является `AREA_OVERLAP`**. Любой классификатор, возвращающий положительную площадь перекрытия для B-1.1, признается дефектным.
- **Статус:** `DERIVED`.

### Случай B-1.2: Отражение конгруэнтной смежной грани (Congruent Boundary Fold)
- **Операция:** Отражение грани $F_2$ относительно общей границы $x = 1$.
- **Преобразование:** $R_{x=1}(x, y) = (2 - x, y)$.
- **Образ:**
  $$R_{x=1}(F_2) = [2 - 2, 2 - 1] \times [0, 2] = [0, 1] \times [0, 2] = F_1$$
- **Аналитический результат:**
  - $\mathcal{I} = F_1 \cap R_{x=1}(F_2) = [0, 1] \times [0, 2]$.
  - Точная площадь перекрытия: $\operatorname{Area}(\mathcal{I}) = 2.0000000$.
  - Классификация контакта: `AREA_OVERLAP`.
- **Статус:** `DERIVED`.

### Случай B-1.3: Отражение меньшей смежной грани (Asymmetric Smaller Face Fold)
- **Конфигурация:**
  - Базовая грань: $F_1 = [0, 1] \times [0, 2]$ (площадь $2.0$).
  - Меньшая смежная грань: $F_3 = [1, 1.5] \times [0, 2]$ (ширина 0.5, высота 2, площадь $S = 1.0$).
- **Операция:** Отражение грани $F_3$ относительно общей границы $x = 1$.
- **Преобразование:** $R_{x=1}(x, y) = (2 - x, y)$.
- **Образ:**
  $$R_{x=1}(F_3) = [2 - 1.5, 2 - 1.0] \times [0, 2] = [0.5, 1.0] \times [0, 2]$$
- **Пересечение с $F_1$:**
  $$\mathcal{I} = F_1 \cap R_{x=1}(F_3) = [0.5, 1.0] \times [0, 2]$$
- **Аналитический результат:**
  - Ширина области перекрытия: $1.0 - 0.5 = 0.5$.
  - Высота: $2.0$.
  - Точная аналитическая площадь: $\operatorname{Area}(\mathcal{I}) = 0.5 \times 2.0 = 1.0000000$.
  - Классификация контакта: `AREA_OVERLAP`.
- **Статус:** `DERIVED`.

### Случай B-1.3-Sym: Симметричный вариант B-1.3 (Отражение большей грани на меньшую)
- **Операция:** Отражение большей грани $F_1 = [0, 1] \times [0, 2]$ относительно $x = 1$ в сторону $F_3 = [1, 1.5] \times [0, 2]$.
- **Образ:** $R_{x=1}(F_1) = [1, 2] \times [0, 2]$.
- **Пересечение с $F_3$:**
  $$\mathcal{I} = R_{x=1}(F_1) \cap F_3 = [1, 2] \times [0, 2] \cap [1, 1.5] \times [0, 2] = [1, 1.5] \times [0, 2]$$
- **Аналитический результат:**
  - Область перекрытия совпадает с самой гранью $F_3$.
  - Точная площадь: $\operatorname{Area}(\mathcal{I}) = 0.5 \times 2.0 = 1.0000000$.
  - Классификация контакта: `AREA_OVERLAP`.
- **Статус:** `DERIVED`.

## 5. Численная политика и допуски

- Порог координат вершин: $\epsilon_{\text{coord}} = 1.0 \times 10^{-7}$.
- Порог площади пересечения: $\epsilon_{\text{area}} = 1.0 \times 10^{-9}$.
- Правило: Если численно вычисленная площадь $\operatorname{Area}_{\text{calc}} \le \epsilon_{\text{area}}$, площадь принудительно обнуляется и контакт классифицируется как `SEGMENT_CONTACT` (если длина отрезка $> \epsilon_{\text{coord}}$) либо `NO_CONTACT`.
