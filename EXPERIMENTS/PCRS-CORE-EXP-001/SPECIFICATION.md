## 1. Назначение и цель эксперимента

Эксперимент `PCRS-CORE-EXP-001` является **минимальным проверочным экспериментом** (Принцип 3 PCRS: *Minimal Experiment First*).

Его цель — изолированно и строго доказать корректность базового механизма геометрических расчётов и независимого аудита на простейшей конфигурации из двух смежных прямоугольных граней, соединенных общей осью сгиба, **до** перехода к многократным и пространственным оригами-конструкциям.

Эксперимент проверяет не физику сминания бумаги, а **математическую состоятельность цепочки «Ядро рассчитывает $\to$ Валидатор проверяет»**.

## 2. Базовая геометрическая конфигурация

- **Пространство:** Двумерное евклидово пространство листа $\mathbb{R}^2$.
- **Базовая грань (Статическая $F_1$):**
  $$F_1 = [0, 1] \times [0, 2] = \{ (x, y) \in \mathbb{R}^2 \mid 0 \le x \le 1, \, 0 \le y \le 2 \}$$
  Вершины: $v_1(0, 0), \, v_2(1, 0), \, v_3(1, 2), \, v_4(0, 2)$. Исходная площадь: $\operatorname{Area}(F_1) = 2.0$.
- **Смежная грань (Подвижная $F_2$):**
  $$F_2 = [1, 2] \times [0, 2] = \{ (x, y) \in \mathbb{R}^2 \mid 1 \le x \le 2, \, 0 \le y \le 2 \}$$
  Вершины: $v_2(1, 0), \, v_5(2, 0), \, v_6(2, 2), \, v_3(1, 2)$. Исходная площадь: $\operatorname{Area}(F_2) = 2.0$.
- **Линия сгиба (Ось отражения $L$):**
  Вертикальная прямая $x = 1$.  
  Единичный вектор нормали: $n = (1, 0)$. Опорная точка на оси: $p_0 = (1, 0)$.

## 3. Спецификация восьми обязательных тестовых сценариев

### Тест 01: Формальное аналитическое определение отражения $R_L$
- **Математическая модель:**  
  Для любой точки $p = (x, y) \in \mathbb{R}^2$:
  $$R_L(p) = p - 2 \big( (p - p_0) \cdot n \big) n = (x, y) - 2 (x - 1)(1, 0) = (2 - x, y)$$
- **Ожидаемый результат для вершин $F_2$:**
  - $R_L(1, 0) = (1, 0)$
  - $R_L(2, 0) = (0, 0)$
  - $R_L(2, 2) = (0, 2)$
  - $R_L(1, 2) = (1, 2)$
- **Критерий прохождения:** $\max_i \|v_i^{\text{calc}} - v_i^{\text{exact}}\|_2 \le \epsilon_{\text{coord}} = 10^{-7}$.
- **Статус:** `SPECIFIED / DERIVED`.

### Тест 02: Неподвижность точек оси сгиба (Stationary Axis Points)
- **Условие:** $\forall p \in L \implies R_L(p) = p$.
- **Проверочные точки:** $p_a = (1, 0)$, $p_b = (1, 1)$, $p_c = (1, 2)$.
- **Ожидаемый результат:** $\|R_L(p) - p\|_2 = 0.0000000$.
- **Критерий прохождения:** Абсолютное расхождение $\le 10^{-9}$.
- **Статус:** `SPECIFIED / DERIVED`.

### Тест 03: Сохранение внутренних расстояний подвижной грани (Изометрия)
- **Условие:** Для любых двух точек $p, q \in F_2$:
  $$\|R_L(p) - R_L(q)\|_2 = \|p - q\|_2$$
- **Проверочные пары:**
  - Горизонтальное ребро: $p = (1, 0), q = (2, 0) \implies \|p - q\| = 1.0$. $\|R_L(p) - R_L(q)\| = \|(1,0) - (0,0)\| = 1.0$.
  - Диагональ грани: $p = (1, 0), q = (2, 2) \implies \|p - q\| = \sqrt{1^2 + 2^2} = \sqrt{5} \approx 2.2360679775$.  
    $\|R_L(p) - R_L(q)\| = \|(1,0) - (0,2)\| = \sqrt{1^2 + 2^2} = \sqrt{5}$.
- **Критерий прохождения:** $|\Delta_{\text{dist}}| \le 10^{-7}$.
- **Статус:** `SPECIFIED / DERIVED`.

### Тест 04: Сохранение площади отражённой грани (Area Invariance)
- **Условие:** $\operatorname{Area}(R_L(F_2)) = \operatorname{Area}(F_2) = 2.0000000$.
- **Метод проверки:** Вычисление ориентированной площади многоугольника по формуле Гаусса (Shoelace formula) по вершинам образа $[(1,0), (0,0), (0,2), (1,2)]$.
- **Ожидаемый результат:** $\operatorname{Area} = 2.0000000$.
- **Критерий прохождения:** $|\operatorname{Area}_{\text{calc}} - 2.0| \le 10^{-9}$.
- **Статус:** `SPECIFIED / DERIVED`.

### Тест 05: Инволютивность преобразования отражения (Involution Property)
- **Условие:** Двукратное применение отражения относительно одной и той же оси тождественно равно единичному оператору:
  $$R_L \circ R_L = \operatorname{id}_{\mathbb{R}^2} \iff R_L(R_L(p)) = p$$
- **Проверка:** Для произвольной внутренней точки $p = (1.732, 0.841) \in F_2$:
  - Шаг 1: $p' = R_L(p) = (2 - 1.732, 0.841) = (0.268, 0.841)$.
  - Шаг 2: $p'' = R_L(p') = (2 - 0.268, 0.841) = (1.732, 0.841) = p$.
- **Критерий прохождения:** $\|p'' - p\|_2 \le 10^{-9}$.
- **Статус:** `SPECIFIED / DERIVED`.

### Тест 06: Трёхстадийная классификация контакта (Tri-State Classification)
- **Подтест 6.1 (До сгиба / Смежное касание по границе):**
  - Область пересечения: $F_1 \cap F_2 = [1, 1] \times [0, 2]$.
  - $\dim = 1$, площадь $\operatorname{Area} = 0.0000000$.
  - Классификация: **`SEGMENT_CONTACT`** (строго НЕ `AREA_OVERLAP`).
- **Подтест 6.2 (После сгиба / Площадное конгруэнтное перекрытие):**
  - Область пересечения: $F_1 \cap R_L(F_2) = [0, 1] \times [0, 2]$.
  - $\dim = 2$, площадь $\operatorname{Area} = 2.0000000$.
  - Классификация: **`AREA_OVERLAP`**.
- **Подтест 6.3 (Отсутствие контакта / Непересекающиеся области):**
  - Дополнительная грань $F_{\text{far}} = [3, 4] \times [0, 2]$.
  - $F_1 \cap F_{\text{far}} = \emptyset$, минимальное расстояние $d = 2.0 > \epsilon$.
  - Классификация: **`NO_CONTACT`**.
- **Критерий прохождения:** Точное совпадение трёх классов без путаницы между $0$-площадным касанием и двумерным перекрытием.
- **Статус:** `SPECIFIED / DERIVED`.

### Тест 07: Реакция независимого валидатора на контролируемый дефект (Negative Control)
- **Цель:** Доказать способность валидатора отбраковывать ложные утверждения (Принцип 1 PCRS).
- **Сценарий 7.1 (Искажение площади):**
  - Агент заявляет, что при отражении $F_2$ получилась площадь перекрытия $3.0$ (вместо $2.0$).
  - Валидатор сопоставляет $3.0$ с аналитическим эталоном $2.0$, фиксирует дельту $|\Delta| = 1.0 > \epsilon$.
  - Ожидаемый вердикт: `VALIDATION_FAILED (DISCREPANCY_BENCHMARK)`.
- **Сценарий 7.2 (Нарушение изометрии):**
  - В образ подмешивается искаженная вершина $v'_5 = (-0.1, 0)$, ребро растягивается до длины $1.1$.
  - Валидатор фиксирует нарушение геометрического инварианта L1: $|1.1 - 1.0| = 0.1 > \epsilon$.
  - Ожидаемый вердикт: `VALIDATION_FAILED (INVARIANT_VIOLATION_ISOMETRY)`.
- **Критерий прохождения:** $100\%$ выявление дефектов, запрет статуса `PASS`.
- **Статус:** `SPECIFIED`.

### Тест 08: Воспроизводимость трассы (Trace Repeatability & Replay)
- **Цель:** Подтверждение Принципа 2 (*Result ≠ Reproducibility*).
- **Спецификация входа:**
  ```json
  {
    "initial_state": {
      "faces": {
        "F1": [[0, 0], [1, 0], [1, 2], [0, 2]],
        "F2": [[1, 0], [2, 0], [2, 2], [1, 2]]
      }
    },
    "trace": [
      {
        "step": 1,
        "operation": "FOLD_REFLECTION",
        "crease_axis": {"point": [1, 0], "normal": [1, 0]},
        "target_face": "F2"
      }
    ]
  }
  ```
- **Проверка:** Функция `REPLAY(initial_state, trace)` на изолированном экземпляре ядра обязана сгенерировать точное результирующее состояние $S_1$ с совпадением FNV-1a сигнатуры:
  $$\operatorname{Hash}(S_1^{\text{replay}}) = \operatorname{Hash}(S_1^{\text{original}})$$
- **Критерий прохождения:** Полная бинарная идентичность нормализованных координат и хешей.
- **Статус:** `SPECIFIED`.
