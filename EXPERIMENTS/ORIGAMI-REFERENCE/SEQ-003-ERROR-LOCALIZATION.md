## 1. Характер инъекции ошибки
В эксперименте SEQ-003 проверяется способность тестового стенда локализовать **первый неверный шаг** в цепочке из трех операций.
- **Правильная последовательность:** $S_0 \xrightarrow{\text{Op 1: } x=1} S_1 \xrightarrow{\text{Op 2: } x=0} S_2 \xrightarrow{\text{Op 3: } y=0} S_3$.
- **Инъекция ошибки в отрицательном контроле:** Для Операции 2 намеренно заменена ось отражения — вместо правильной оси $x = 0$ используется ось $x = 1$ (анкер `[1,0]`, направление `[0,1]`). 
- **Распространение ошибки:** Операция 3 получает фактическое возвращённое состояние ошибочной Операции 2.

## 2. Состояния $S_0, S_1, S_2$ (Ошибочное) и $S_3$ (Ошибочное)
- **Начальное состояние ($S_0$):**
  - $A = (1, 0), B = (2, 0), C = (2, 2), D = (1, 2)$
- **Шаг 1 ($S_1$ — Корректный, совпадает с эталоном):**
  - $A_1 = (1, 0), B_1 = (0, 0), C_1 = (0, 2), D_1 = (1, 2)$
- **Шаг 2 ($S_2^{\text{err}}$ — Ошибочный из-за неправильной оси $x=1$):**
  - $A_2^{\text{err}} = (1, 0)$
  - $B_2^{\text{err}} = (2, 0)$
  - $C_2^{\text{err}} = (2, 2)$
  - $D_2^{\text{err}} = (1, 2)$
- **Шаг 3 ($S_3^{\text{err}}$ — Распространение ошибки после $y=0$):**
  - $A_3^{\text{err}} = (1, 0)$
  - $B_3^{\text{err}} = (2, 0)$
  - $C_3^{\text{err}} = (2, -2)$
  - $D_3^{\text{err}} = (1, -2)$
