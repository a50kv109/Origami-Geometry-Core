## 1. Описание последовательности и цель

Эксперимент SEQ-002 реализует цепочку из трёх зависимых геометрических отражений на замороженном ядре PCRS с независимой верификацией каждого промежуточного состояния ($S_0 \to S_1 \to S_2 \to S_3$):
- **Операция 1:** Отражение относительно вертикальной оси $x = 1$ (анкер `[1,0]`, направление `[0,1]`).
- **Операция 2:** Отражение относительно вертикальной оси $x = 0$ (анкер `[0,0]`, направление `[0,1]`), применяемое к фактическому возвращённому состоянию Операции 1 ($S_1$).
- **Операция 3:** Отражение относительно горизонтальной оси $y = 0$ (анкер `[0,0]`, направление `[1,0]`), применяемое к фактическому возвращённому состоянию Операции 2 ($S_2$).

## 2. Фактические состояния $S_0, S_1, S_2, S_3$

- **Начальное состояние ($S_0$) — Прямоугольник $[1,2] \times [0,2]$:**
  - $A = (1, 0)$
  - $B = (2, 0)$
  - $C = (2, 2)$
  - $D = (1, 2)$
- **Промежуточное состояние ($S_1$) — После Operation 1 ($x = 1$):**
  - $A_1 = (1, 0)$
  - $B_1 = (0, 0)$
  - $C_1 = (0, 2)$
  - $D_1 = (1, 2)$
- **Промежуточное состояние ($S_2$) — После Operation 2 ($x = 0$):**
  - $A_2 = (-1, 0)$
  - $B_2 = (0, 0)$
  - $C_2 = (0, 2)$
  - $D_2 = (-1, 2)$
- **Конечное состояние ($S_3$) — После Operation 3 ($y = 0$):**
  - $A_3 = (-1, 0)$
  - $B_3 = (0, 0)$
  - $C_3 = (0, -2)$
  - $D_3 = (-1, -2)$

## 4. Проверки инвариантов на каждом шаге

1. **Изометрия (сохранение попарных расстояний):** Выполнено ($S_0 \leftrightarrow S_1 \leftrightarrow S_2 \leftrightarrow S_3$, $\Delta \le 10^{-7}$).
2. **Беззнаковая площадь:** Постоянна и равна $2.0$ на каждом шаге ($S_0, S_1, S_2, S_3$, $\Delta \le 10^{-9}$).
3. **Знаковая площадь и чередование ориентации:**
   - $S_0$: $+2.0$ (Counter-Clockwise)
   - $S_1$: $-2.0$ (Clockwise, инверсия после Op 1)
   - $S_2$: $+2.0$ (Counter-Clockwise, восстановление после Op 2)
   - $S_3$: $-2.0$ (Clockwise, повторная инверсия после Op 3)
4. **Неподвижность точек на осях сгиба:** Точки, лежащие на осях $x=1, x=0$ и $y=0$, продемонстрировали нулевое смещение ($\Delta \le 10^{-9}$).
