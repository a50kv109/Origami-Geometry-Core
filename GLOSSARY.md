## 1. Геометрические понятия и объекты

### 1.1. Лист бумаги (Paper Sheet, $\mathcal{S}$)
Связное замкнутое компактное 2D-многообразие с кусочно-гладкой границей в $\mathbb{R}^2$. В базовой модели PCRS каноническим листом является единичный квадрат:
$$\mathcal{S}_0 = [0, 1] \times [0, 1] \subset \mathbb{R}^2$$

### 1.2. Линия сгиба (Crease Line / Fold Line, $L$)
Прямая на плоскости листа $\mathbb{R}^2$, задаваемая уравнением:
$$L = \{ p \in \mathbb{R}^2 \mid n \cdot (p - p_0) = 0 \}$$
где $n = (n_x, n_y)$ — единичный вектор нормали ($\|n\|_2 = 1$), а $p_0$ — опорная точка на прямой.  
Линия сгиба разбивает лист $\mathcal{S}$ на две области (или пересекает его по внутреннему отрезку сгиба $C = L \cap \mathcal{S}$).

### 1.3. Статическая и подвижная грани (Static and Moving Regions)
При выполнении операции сгиба относительно $L$:
- **Статическая грань ($\mathcal{F}_{\text{static}}$):** Подмножество листа, координаты которого сохраняются неизменными в базисной системе отсчёта:
  $$\mathcal{F}_{\text{static}} = \{ p \in \mathcal{S} \mid n \cdot (p - p_0) \le 0 \}$$
- **Подвижная грань ($\mathcal{F}_{\text{moving}}$):** Подмножество листа, подвергающееся пространственной трансформации:
  $$\mathcal{F}_{\text{moving}} = \{ p \in \mathcal{S} \mid n \cdot (p - p_0) \ge 0 \}$$

### 1.4. Операция зеркального отражения сгиба ($R_L$)
Изометрическое преобразование плоскости $\mathbb{R}^2 \to \mathbb{R}^2$ относительно прямой $L$:
$$R_L(p) = p - 2 \big( (p - p_0) \cdot n \big) n$$
Для любого отрезка $[a, b]$ сохраняется евклидова длина: $\|R_L(a) - R_L(b)\| = \|a - b\|$.

### 1.5. Сложенная подвижная грань ($\mathcal{F}'_{\text{moving}}$)
Геометрический образ подвижной грани после завершения сгиба на угол $\pi$ ($180^\circ$):
$$\mathcal{F}'_{\text{moving}} = R_L(\mathcal{F}_{\text{moving}})$$

## 2. Классификация геометрических контактов и перекрытий

### 2.1. Множество геометрического пересечения ($\mathcal{I}$)
Множество точек взаимного пересечения проекций статической грани и отражённой подвижной грани:
$$\mathcal{I} = \mathcal{F}_{\text{static}} \cap \mathcal{F}'_{\text{moving}}$$

### 2.2. Категории контактов (Contact Classification)

1. **Площадное перекрытие (Area Overlap, 2D-перекрытие):**
   - Топологическая размерность пересечения: $\dim(\mathcal{I}) = 2$.
   - Мера Жордана (площадь): $\operatorname{Area}(\mathcal{I}) > 0$.
   - Означает наличие двумерного полигона взаимного перекрытия проекций.

2. **Отрезковое / Рёберное касание (Segment / Edge Contact, 1D-контакт):**
   - Топологическая размерность пересечения: $\dim(\mathcal{I}) = 1$.
   - Площадь: $\operatorname{Area}(\mathcal{I}) = 0$.
   - Пересечение представляет собой один или несколько отрезков ненулевой длины ($\operatorname{Length} > 0$).

3. **Точечное / Вершинное касание (Vertex / Point Contact, 0D-контакт):**
   - Топологическая размерность пересечения: $\dim(\mathcal{I}) = 0$.
   - Площадь: $\operatorname{Area}(\mathcal{I}) = 0$.
   - Пересечение состоит из изолированной вершины или дискретного набора точек.

4. **Отсутствие контакта (Disjoint / No Overlap):**
   - $\mathcal{I} = \emptyset$.
   - Проекции не имеют общих точек в пределах допуска $\epsilon$.

5. **Смешанная геометрия (Mixed Contact Geometry):**
   - Ситуация, когда замкнутые полигоны $\mathcal{F}_{\text{static}}$ и $\mathcal{F}'_{\text{moving}}$ касаются одновременно по вершине/отрезку внешней границы и пересекаются в другой части с ненулевой площадью $\operatorname{Area} > 0$.
   - *Контракт PCRS:* если $\operatorname{Area}(\mathcal{I}) > \epsilon$, классификация обязана содержать компонент `AREA_OVERLAP` с дополнительным флагом граничных контактов `BOUNDARY_CONTACT_PRESENT`.

## 3. Системные и архитектурные сущности

### 3.1. Геометрическое состояние (State)
Иммутабельная структура данных, описывающая геометрию и топологию модели на дискретном шаге времени $t_k$.  
Содержит: список 2D-вершин, список ориентированных рёбер, список плоских полигональных граней и матрицу/граф относительного порядка слоев (Layer Stacking Graph).

### 3.2. Трасса операций (Trace)
Строго детерминированная упорядоченная последовательность параметров сгибов $\langle O_1, O_2, \dots \rangle$, позволяющая однозначно воспроизвести состояние $State_k$ из исходного состояния $State_0$.

### 3.3. Отчёт независимой верификации (Verification Report)
Структурированный документ аудита, генерируемый независимым валидатором без использования внутренних промежуточных данных вычислительного ядра. Содержит булевы статусы инвариантов, метрики расхождения с эталоном и класс контакта.

### 3.4. Аналитический эталон (Analytical Benchmark / Ground Truth)
Символически или аналитически вычисленный математический результат задачи (точные координаты точек, площади в виде рациональных чисел $\frac{p}{q}$ или радикалов), служащий абсолютным критерием истинности для проверки численного ядра.

### 3.5. Допуск численной устойчивости ($\epsilon$, Numerical Tolerance)
Малый скаляр $\epsilon \in [10^{-9}, 10^{-6}]$, используемый для предикатов равенства вещественных чисел и определения вырожденности геометрических примитивов:
$$|x - y| \le \epsilon \implies x \approx_\epsilon y$$
