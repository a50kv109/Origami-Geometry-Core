# Testing Instructions

## Running Tests

To run the core baseline tests:
```bash
npm test
```

To run experimental cross-domain branch selection tests:
```bash
npm run test:exp
```

## Test Coverage
- **Core Baseline:** 15 primary tests, 3 audit tests, 6 schema validation tests.
- **Experimental:** EXP-GGR-01 branch selection and verification suites.
