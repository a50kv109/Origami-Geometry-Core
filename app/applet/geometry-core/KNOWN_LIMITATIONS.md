# Known Limitations

- **Continuous Manifolds:** No support for representing or solving continuous degrees of freedom (DOF >= 1).
- **Numerical Bifurcations:** Sensitivity to near-zero discriminant values; reliance on epsilon-based thresholds.
- **2D Primitives:** Minimal set of 2D primitives currently available in experimental modules.
- **Verification:** Independent verification is implemented for specific benchmarks but not yet generalized for all reasoning stages.
- **Documentation:** This repository is in a pre-publication phase; some documentation is placeholder or conceptual.
